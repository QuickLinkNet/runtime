# Third-party notices

RUNTIME uses third-party packages declared in `package.json` and locked in `package-lock.json`. Those packages remain under their respective licenses; the RUNTIME licenses do not replace them.

Direct runtime dependencies:

| Package | License |
| --- | --- |
| React | MIT |
| React DOM | MIT |
| React Router DOM | MIT |

Direct development and deployment dependencies use MIT or Apache-2.0 licenses. The complete locked dependency graph currently declares MIT, Apache-2.0, ISC, BSD-3-Clause or CC-BY-4.0 licenses. `caniuse-lite` supplies CC-BY-4.0 browser compatibility data to the build toolchain.

Exact versions and transitive packages are recorded in `package-lock.json`. Installed packages include their full license texts in their package directories. Distributors of modified or prebuilt bundles are responsible for retaining all notices required by those licenses.
